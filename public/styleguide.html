Rail 40px / buttons 32px / drawer 260px default with a drag-to-resize grip on its right edge (teal on hover) / rows 24px — denser than TM2020, always. Layers: active layer = orange edge bar; double-click renames inline (teal-bordered input); ✕ deletes with a confirm warning; the gear toggles that layer's settings — settings are never visible by default. Scrollbars are 8px, bg-3 thumb, teal-dim on hover, everywhere.

05 / Dialogs (and dialogs over dialogs)

Map settings✕
Base, mood and name — list rows reuse the drawer's row grammar (teal edge bar on the active choice).
Delete layer✕
Delete layer "Scenery" and its 210 placements? Undo with Ctrl+Z if you change your mind.

Chamfered top-right (12px), skewed teal title chip, dimmed backdrop (55% void). Dialogs stack: each opens above the last with its own backdrop dim; Esc / ✕ / backdrop-click closes only the top one. Destructive confirms use the danger button, never a red header.

06 / Viewport furniture

  • Orange — layer plane outlines (bright = active, dim = others)
  • Gold — selection boxes, HUD sequence letters
  • Green — height guides, plumb line, "aligned" feedback
  • Teal — reserved for future snapping guides
  • Ghosts: 45% opacity clones of the real mesh, always

07 / Do & don't

  • ✔ tighter is better — 8px padding, 4px gaps, 24px rows
  • ✔ every action shows its shortcut in the tooltip
  • ✔ 120–180ms motion, one easing curve, no bounces
  • ✘ Nadeo green, checkered-fade backgrounds, parallelogram cards
  • ✘ two accents on one element
  • ✘ drop shadows (except the drawer slide-over)
  • ✘ binding the S key — it belongs to flight
